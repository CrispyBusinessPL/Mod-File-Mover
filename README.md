## Description

This script moves Paralives mods from the Steam Workshop Mods folder to the correct folder for each type of mod. The script will then delete any remaining empty folders in the workshop mods folder. The script will not execute until permission is granted and after a basic integrity check of current mod files. Debug mode can be turned on using the config file to simulate running the script without making changes. When debug mode has been properly activated a message will display stating debug mode is active.

## Requirements

* Requires Paralives game installed using Steam.

## Installation

* No installation required.
* Script can be run from any location.
* Does not matter if the game is running or not.

## How to Use

1. Run the executable file.
2. Review the generated report.
3. Post the text file to the Paralives Discord if you would like more information or help fixing the identified issues.

## Configuration

* The program has an optional `config.txt` file for overriding the default file paths.
